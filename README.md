# CF Hockey League Site

Starter Next.js site for the Cold Fusion Summer Hockey League.

## Pages
- `/` public league site
- `/admin` admin sign-in scaffold

## Environment variables
Copy `.env.example` values into Vercel or a local `.env.local` file:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

## Local run
```bash
npm install
npm run dev
```
